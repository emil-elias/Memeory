# Memeory

A browser memory with database, user accounts, statistics, leaderboard and admin panel, developed by Ruven Bellmann & Emil Wilde.

This application was created as part of an excercise from the lecture "Web Application Development" at the University of Bremen in 2023.
The final version is in the directory "V4".

You'll need an additional SQL database, which you'll have to connect in setupDB.php.
